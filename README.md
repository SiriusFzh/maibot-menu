# MaiBot 菜单插件

发送 `/菜单` 即可生成一张精美的菜单图片，列出麦麦的所有可用功能和指令。

## 功能

- 完全手动配置，只显示你自己添加的功能和指令
- 支持在 WebUI 插件配置页面中添加/编辑/删除功能分组
- 支持在功能分组下添加子项（指令 + 描述）
- 以卡片式图片展示，风格统一美观
- 图片渲染失败时自动降级为纯文本

## 安装

手动将本仓库克隆到 MaiBot 的 `plugins/` 目录，然后在 WebUI 插件管理页面启用。官方插件市场收录后，也可搜索 `maibot.menu` 安装。

## 使用

在任何群聊中发送：

```
/菜单
```

麦麦会生成一张图片，列出你配置的所有功能和指令。

## 配置

`config.toml` 由 MaiBot 根据插件配置模型自动生成，不纳入版本管理。仓库中的 `config.example.toml` 保留功能分组示例，可按需复制到本地生成的配置中。


在 MaiBot WebUI 的插件配置页面中，找到「菜单」标签页下的「功能列表」，即可：

1. **添加功能**：点「添加项目」输入功能名称（如"每日分析"）
2. **添加指令**：在功能下的「指令列表」点「添加项目」，填写格式 `命令 : 描述`
3. **删除**：鼠标悬停在项目上点击删除按钮

配置示例：

```toml
[[menu.features]]
name = "每日分析"
commands = [
    "/summary : 查看今天的群聊总结",
    "/summary 昨天 : 查看昨天的群聊总结",
    "/mysummary : 查看自己今天的个人总结",
]
```

## 菜单管理命令与数据

支持 `/菜单添加 功能名`、`/菜单指令 功能名 指令 描述`、`/菜单删除 功能名`、`/菜单删指令 功能名 指令`。这些命令当前对所有聊天用户开放，修改的是机器人共用菜单；请只在可信聊天环境启用。管理命令与 WebUI 配置合并展示。

SDK 最低版本为 2.6.0。命令新增的菜单数据保存在 `self.ctx.paths.data_dir` 下的 `commands.json`，升级时可保留。首次加载新版时会从本插件旧安装目录复制已有 `commands.json`；已有持久化数据不会被覆盖，旧文件也不会被删除。菜单使用系统字体，不需要安装其他插件。
